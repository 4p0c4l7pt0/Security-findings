# ⚖️ Legal Disclaimer

## Publication Rights

All penetration test reports, security assessments, and vulnerability findings published in this repository were:

1. **Conducted under formal written agreements** between Sadra Secure Corp. (کیان امن صدرا) and the respective client organisations.
2. **Authorised in scope** — all testing was performed exclusively within the agreed target systems and time windows.
3. **Post-NDA publication** — the non-disclosure period has elapsed for every engagement documented here. Written client permission for publication was obtained prior to any public release.
4. **Anonymised where required** — any real user PII, production credentials, internal infrastructure details, or data that could harm individuals or systems has been removed or redacted.

## What Is and Is Not Published

**Published:**
- Vulnerability descriptions, classification, and CVSSv3.1 severity ratings
- Generic proof-of-concept request/response patterns (no ready-to-run weaponised code)
- Original screenshots from the assessment documentation
- Remediation guidance

**Not Published:**
- Valid session tokens, API keys, or authentication credentials
- Exact internal IP addresses of production systems
- Personal data of affected users
- Full working exploit automation scripts capable of direct misuse against production systems

## Responsible Disclosure

All findings were reported to the respective client security teams through formal written reports with:
- Full technical reproduction steps
- CVSSv3.1 severity ratings
- Prioritised remediation roadmaps
- Remediation verification (re-testing)

No vulnerabilities in this portfolio were disclosed publicly before the client had a reasonable opportunity to remediate.
