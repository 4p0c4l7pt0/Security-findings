# Security Findings — CTF Content Package

This package is ready to merge into the root of a GitHub Pages/Jekyll repository.

## Contents

- `ctf/hardware/its-oops-tpm.md`
- `ctf/hardware/critical-flight.md`
- `assets/images/ctf/hardware-its-oops-tpm/`
- `assets/images/ctf/hardware-critical-flight/`
- `CTF-INDEX-SNIPPET.md`

## Installation

1. Extract this package.
2. Upload the `ctf/` and `assets/` folders to the root of the GitHub repository.
3. Add the links from `CTF-INDEX-SNIPPET.md` to the site's main navigation or homepage.
4. Commit the changes.
5. Wait for GitHub Pages to rebuild the site.

The Markdown files use `relative_url` for images and internal links, which helps them work correctly on a GitHub Pages project site with a repository base path.
